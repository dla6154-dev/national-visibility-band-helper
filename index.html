API 확인 중

              

            

          


          
시계제한과 기상악화 문구를 한 화면에서 다루도록 구성했고, 그룹별 자유문구를 넣으면 그 문구 아래에 항로 목록이 이어집니다. 공공데이터 운항 API는 첫 화면 진입 때 1회 자동으로 읽고, 이후에는 `데이터 새로고침`을 눌렀을 때만 다시 읽습니다. 편도 항로는 왕복 2건을 1항차로 묶어 뒤쪽 편도는 숨깁니다.

              사용 방법
